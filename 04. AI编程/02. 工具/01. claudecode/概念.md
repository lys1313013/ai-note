Claude Code 的能力可以按照7层扩展（harness)来理解。Antropic 官方在2026年5月的企业级指南中总结了这个框架：
1. CLAUDE.md —— 项目说明书，每次会话自动加载
2. Hooks —— 事件触发器，在特定实际自动执行
3. Skills —— 专业知识包， AI 按需执行
4. Plugins —— 把 Skills + Hooks + MCP 打包分发
5. LSP —— 给 AI 装上 IDE 级的代码导航
6. MCP —— 链接外部工具和数据源
7. 子 Agent —— 独立上下文并行干活
这7层从底向上，每一层建议在前一层之上。前3层是基础配置，后7层是高级拓展。本部分和第四部分回逐个展开。
官方反复强调一个观点：模型能力是底板，配置质量才是天花板。花时间把配置做好，比追最新模型版本更有实际收益。

3.2.2 CLAUDE.md 你的项目说明书
CLAUDE.md 是 Claude Code 中最重要的配置文件之一。它就像你给新来的实习生写的“项目入职手册” —— 告诉 AI 这个项目的北京、技术栈、编码规范和当前进度
为什么 CLAUDE.md 如此重要？
没有 CLAUDE.md时，Claude Code 每次开始工作都要花时间”重新认识“你的项目。有了 CLAUDE.md，它一启动就知道项目的全部背景，效率大幅提升。
