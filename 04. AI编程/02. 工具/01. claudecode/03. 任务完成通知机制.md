# Claude Code 任务完成通知机制（Hook + session_id 多会话隔离）

## 目标

Claude Code 在终端跑任务时，人往往切到别的窗口做其他事。这套机制实现：

- 任务完成（Agent 停止响应）时弹出 macOS 系统通知，通知内容显示**本会话用户最后发的消息**前 40 个字，一眼知道是哪个任务完成了
- 如果用户**正盯着当前终端窗口**，不弹通知（避免打扰）
- **多窗口/多会话并行时互不串消息**：A 窗口完成只显示 A 的消息，不会显示成 B 的

## 整体流程

```
用户发送消息
    │
    ▼
UserPromptSubmit hook ──→ save-prompt.sh
    │                       按 session_id 写入：
    │                       /tmp/claude-notify/<session_id>.prompt  (用户消息)
    │                       /tmp/claude-notify/<session_id>.tty     (终端 TTY)
    ▼
Claude 执行任务……
    │
    ▼
Stop hook ────────────→ stop-notify.sh
                            1. 从 stdin 读 session_id
                            2. 读本会话的 .tty，与前台窗口 TTY 比对
                               一致 → 用户正在看，退出不通知
                            3. 读本会话的 .prompt，截断 40 字
                            4. terminal-notifier 弹系统通知
    │
    ▼
SessionEnd hook ──────→ cleanup-notify.sh
                            删除本会话的两个文件 +
                            清理 /tmp/claude-notify 下超过 1 天的残留
```

## 核心机制：Hook 的 stdin JSON

Claude Code 触发 hook 时，通过 **stdin 向脚本传入一段 JSON**，公共字段：

| 字段 | 说明 |
|---|---|
| `session_id` | 当前会话 ID（UUID），多会话隔离的 key |
| `transcript_path` | 会话 transcript JSONL 文件路径 |
| `cwd` | 工作目录 |
| `hook_event_name` | 事件名，如 `UserPromptSubmit`、`Stop` |

不同事件附加各自字段：`UserPromptSubmit` 带 `prompt`，`Stop` 带 `stop_hook_active` 等。

脚本里用 `jq` 提取：

```bash
input=$(cat)
sid=$(echo "$input" | jq -r '.session_id // empty')
```

## 多会话串消息问题与解法

### 问题

初版实现用两个全局共享文件：

- `/tmp/claude-tty.txt`
- `/tmp/claude-last-prompt.txt`

单会话没问题。多窗口并行时，A、B 两个会话都写这两个文件，**后写覆盖先写**——A 任务完成时弹出的通知可能显示 B 的消息。

### 解法

把共享文件改成**按 session_id 分文件**：

```
/tmp/claude-notify/
├── <session-id-A>.prompt   # A 会话的消息
├── <session-id-A>.tty      # A 会话所在终端的 TTY
├── <session-id-B>.prompt
└── <session-id-B>.tty
```

- 写入端（UserPromptSubmit）：只写自己 session_id 的文件
- 读取端（Stop）：只读自己 session_id 的文件
- 清理端（SessionEnd）：只删自己 session_id 的文件

`session_id` 在同一进程生命周期内不变，且每会话唯一（即使同一项目目录开多个窗口），可直接当文件名用，无需转义。

## 三个脚本

### 1. `~/.claude/save-prompt.sh`（UserPromptSubmit）

```bash
#!/bin/bash
# 按 session_id 保存用户最后一条消息和当前终端 TTY
input=$(cat)

sid=$(echo "$input" | jq -r '.session_id // empty' 2>/dev/null)
[ -z "$sid" ] && exit 0

dir=/tmp/claude-notify
mkdir -p "$dir"

# 保存当前终端 TTY，用于 Stop 时判断用户是否还在这个窗口前
our_tty=$(ps -o tty= -p $$ 2>/dev/null | tr -d ' ')
if [ -n "$our_tty" ] && [ "$our_tty" != "?" ]; then
  echo "$our_tty" > "$dir/$sid.tty"
fi

user_msg=$(echo "$input" | jq -r '
  .prompt // .message // .user_message // .text // .input //
  (.messages // [] | map(select(.role == "user")) | last | .content // empty) //
  empty
' 2>/dev/null)

if [ -n "$user_msg" ] && [ "$user_msg" != "null" ]; then
  echo "$user_msg" > "$dir/$sid.prompt"
fi
```

### 2. `~/.claude/stop-notify.sh`（Stop）

```bash
#!/bin/bash
# 任务完成时弹系统通知；用户正看着当前窗口则不弹
input=$(cat)

sid=$(echo "$input" | jq -r '.session_id // empty' 2>/dev/null)

dir=/tmp/claude-notify
our_tty=""
user_msg=""
if [ -n "$sid" ]; then
  our_tty=$(cat "$dir/$sid.tty" 2>/dev/null)
  user_msg=$(cat "$dir/$sid.prompt" 2>/dev/null)
fi

front_app=$(osascript -e 'tell application "System Events" to get name of first application process whose frontmost is true' 2>/dev/null)

# 前台是终端应用时，精确比对该窗口是不是当前窗口
if [ -n "$our_tty" ] && [ -n "$front_app" ]; then
  case "$front_app" in
    Terminal)
      front_tty=$(osascript -e 'tell application "Terminal" to get tty of front window' 2>/dev/null)
      [ "$front_tty" = "$our_tty" ] && exit 0
      ;;
    iTerm2)
      front_tty=$(osascript -e 'tell application "iTerm2" to get tty of current session of current window' 2>/dev/null)
      [ "$front_tty" = "$our_tty" ] && exit 0
      ;;
  esac
fi

if [ -z "$user_msg" ]; then
  /opt/homebrew/bin/terminal-notifier \
    -title "Claude Code" \
    -message "任务已完成" \
    -sound default &
  exit 0
fi

# 按字符截断，避免中文乱码
if [ ${#user_msg} -gt 40 ]; then
  preview="${user_msg:0:40}..."
else
  preview="$user_msg"
fi

/opt/homebrew/bin/terminal-notifier \
  -title "Claude Code" \
  -message "$preview" \
  -sound default &
```

### 3. `~/.claude/cleanup-notify.sh`（SessionEnd）

```bash
#!/bin/bash
# 会话退出时删除本会话文件，防止 /tmp/claude-notify 堆积
input=$(cat)

sid=$(echo "$input" | jq -r '.session_id // empty' 2>/dev/null)
[ -z "$sid" ] && exit 0

rm -f "/tmp/claude-notify/$sid.tty" "/tmp/claude-notify/$sid.prompt"

# 兜底：清理超过一天没人认领的残留（进程被 kill 导致 SessionEnd 未触发）
find /tmp/claude-notify -type f -mtime +1 -delete 2>/dev/null
```

## Hook 注册（`~/.claude/settings.json`）

```json
{
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [ { "type": "command", "command": "bash /Users/hurry/.claude/save-prompt.sh" } ] }
    ],
    "Stop": [
      { "hooks": [ { "type": "command", "command": "bash /Users/hurry/.claude/stop-notify.sh" } ] }
    ],
    "SessionEnd": [
      { "hooks": [ { "type": "command", "command": "bash /Users/hurry/.claude/cleanup-notify.sh" } ] }
    ]
  }
}
```

settings.json 热加载，改完无需重启 Claude Code。

## 依赖

- `jq`：解析 hook 的 stdin JSON
- `terminal-notifier`（`/opt/homebrew/bin/terminal-notifier`）：macOS 系统通知，`brew install terminal-notifier`
- `osascript`：macOS 自带，用于获取前台应用和终端窗口 TTY

## 注意事项与边界情况

1. **session_id 会在 resume 时变化**：`claude -c` / `--resume` 恢复会话时会分配新的 session_id。不影响正确性——同一进程生命周期内写和读的 ID 一致；旧 ID 的残留文件由 SessionEnd 清理和 1 天 TTL 兜底。
2. **TTY 检测是"正在看不打扰"的关键**：hook 脚本通过 `ps -o tty= -p $$` 拿到自己所在终端的 TTY，再与 Terminal/iTerm2 前台窗口的 TTY 比对。每个会话各自记录，多窗口时比对的是自己窗口，不会误判。
3. **prompt 文件在 Stop 后不删除**：Stop 每轮对话结束都会触发，文件留着等下一条消息覆盖即可，统一由 SessionEnd 清理。
4. **拿不到 session_id 时静默退出**：三个脚本都是 `[ -z "$sid" ] && exit 0`，不会写共享文件造成污染（Stop 脚本除外：sid 为空时降级为通用通知）。
5. **调试技巧**：手动模拟 hook 触发——`echo '{"session_id":"test-1","prompt":"试试"}' | bash ~/.claude/save-prompt.sh`，然后检查 `/tmp/claude-notify/` 下的文件。
